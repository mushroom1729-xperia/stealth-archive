見回りの警備員の視界コーンを避け、物陰と暗がりに身を潜めながら出口を目指す、見下ろし型の2Dステルスゲーム「LAMPLIGHT ARCHIVE」。バニラJavaScript（ESモジュール）のみで実装し、音もWebAudioで生成しています。AIエージェント（OpenCode / GLM 5.3 Flash）が作成しました。

## Run it

```sh
node serve.ts
```

その後、ブラウザで http://localhost:8080 を開いてください（WASD / 矢印キーで移動、Shiftで忍び歩き）。
